## Vercel Analytics e Speed Insights

Este projeto utiliza recursos da Vercel para análise e monitoramento:

- Vercel Web Analytics: visitantes, page views, usuários online e origem de acesso.
- Vercel Speed Insights: métricas reais de performance e experiência do usuário.

Após o deploy em produção:
1. Acesse o domínio publicado.
2. Navegue por algumas páginas ou seções.
3. Abra o painel da Vercel.
4. Verifique as abas Analytics e Speed Insights.
5. Aguarde alguns minutos para os dados aparecerem.

Observação:
Os dados podem não aparecer imediatamente. Bloqueadores de anúncios, extensões de privacidade e acessos locais podem impedir ou atrasar a coleta.
